# APGI-Signature

A comprehensive psychological assessment application that helps users understand their cognitive and emotional processing styles through the Active Predictive Guidance Integration (APGI) model. Built with SwiftUI for a seamless cross-platform experience on iOS and macOS.

## 🌟 Key Features

### 🧠 Core Psychological Assessment
- **29 scientifically-validated questions** across 7 key dimensions
- **Adaptive scoring algorithm** with reliability weighting for each question
- **Real-time progress tracking** with visual feedback
- **Response validation** to ensure result accuracy and consistency
- **Confidence scoring** that evaluates response patterns for reliability

### 🔍 Advanced Profile Analysis
- **Four Core Parameters**:
  - **Prediction Error Sensitivity (ε)**: Measures sensitivity to unexpected events and changes
  - **Precision Allocation (π)**: Analyzes how you prioritize different information sources
  - **Ignition Threshold (θₜ)**: Assesses your attentional focus and awareness levels
  - **Somatic Bias (β)**: Evaluates your body awareness and interoceptive sensitivity
- **Secondary Analysis**:
  - Cross-parameter interaction analysis
  - Temporal stability assessment
  - Environmental context evaluation
  - Response consistency metrics

### 📊 Interactive Visualization & Reporting
- **Dynamic Radar Charts**: Visual representation of your psychological profile
- **State Explorer**: Interactive visualization of psychological states and transitions
- **Profile Comparison**: Side-by-side comparison of multiple profiles
- **Comprehensive Reports**: Generate detailed PDF reports for personal or clinical use
- **Parameter-Specific Insights**: Detailed breakdown of each parameter's influence

### 🎯 Cognitive Profile Types
Detailed analysis of 8 distinct cognitive profiles, each with unique characteristics:

1. **Sensitive Integrator** (Orange) - High awareness of prediction errors and bodily responses
2. **Analytical Guard** (Blue) - Strong mental models with precise vigilance
3. **Adaptive Balancer** (Green) - Maintains equilibrium between exploration and stability
4. **Open Explorer** (Pink) - Thrives on novelty and new experiences
5. **Contemplative Anchor** (Teal) - Maintains calm and reflection across contexts
6. **Somatic Navigator** (Purple) - Deeply attuned to bodily sensations and intuition
7. **Cognitive Architect** (Mint) - Strong theoretical and strategic planning abilities
8. **Dynamic Responder** (Red) - Quick to respond to emotional and situational changes

## 🚀 Getting Started

### Usage
1. **Taking the Assessment**
   - Launch the app and select "Begin Assessment"
   - Answer all questions honestly (takes ~10-15 minutes)
   - Use the progress tracker to monitor your completion
   - Review your detailed profile analysis upon completion

2. **Exploring Results**
   - View your primary profile type with color-coded identification
   - Examine detailed parameter scores with visual indicators
   - Explore interactive visualizations including radar charts
   - Access personalized insights and recommendations
   - Compare with previous assessments using the Profile Comparison tool
   - Export comprehensive PDF reports for professional consultation

3. **Advanced Features**
   - **State Explorer**: Visualize psychological states and transitions
   - **Profile Comparison**: Compare multiple profiles side-by-side
   - **Parameter Analysis**: Deep dive into each psychological parameter
   - **Data Export**: Save results as PDF for record-keeping or professional review
   - **Keyboard Navigation**: Full keyboard support for accessibility
