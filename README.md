# APGI-Signature

A comprehensive psychological assessment application that helps users understand their cognitive and emotional processing styles through the Active Predictive Guidance Integration (APGI) model. Built with SwiftUI for a seamless cross-platform experience on iOS and macOS.

## 🌟 Key Features

### 🧠 Core Psychological Assessment
- **35+ scientifically-validated questions** across 7 key dimensions
- **Adaptive scoring algorithm** with reliability weighting
- **Real-time progress tracking** with visual feedback
- **Response validation** to ensure result accuracy and consistency

### 🔍 Advanced Profile Analysis
- **Four Core Parameters**:
  - **Prediction Error Sensitivity (ε)**: Measures sensitivity to unexpected events
  - **Precision Allocation (π)**: Analyzes information source prioritization
  - **Ignition Threshold (θₜ)**: Assesses attentional focus and awareness
  - **Somatic Bias (β)**: Evaluates body awareness and interoception
- **Secondary Metrics**:
  - Cross-parameter interaction analysis
  - Temporal stability assessment
  - Environmental fit evaluation

### 📊 Interactive Visualization
- **Dynamic Radar Charts**: Visual representation of psychological profile
- **State Explorer**: Interactive visualization of psychological states
- **Profile Comparison**: Side-by-side comparison of multiple profiles
- **Export to PDF**: Generate professional reports for personal or clinical use

### 🎯 Cognitive Profile Types
Detailed analysis of 8 distinct cognitive profiles:

1. **Sensitive Integrator** - High awareness of prediction errors and bodily responses
2. **Analytical Guard** - Strong mental models with precise vigilance
3. **Adaptive Balancer** - Maintains equilibrium between exploration and stability
4. **Open Explorer** - Thrives on novelty and new experiences
5. **Contemplative Anchor** - Maintains calm and reflection across contexts
6. **Somatic Navigator** - Deeply attuned to bodily sensations and intuition
7. **Cognitive Architect** - Strong theoretical and strategic planning abilities
8. **Dynamic Responder** - Quick to respond to emotional and situational changes

## 🚀 Getting Started

### Prerequisites
- Xcode 14.0+
- iOS 16.0+ / macOS 13.0+
- Swift 5.7+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/APGI-Signature.git
   ```
2. Open `APGI-Signature.xcodeproj` in Xcode
3. Select your target device or simulator
4. Build and run (⌘R)

### Usage
1. **Taking the Assessment**
   - Launch the app and select "Begin Assessment"
   - Answer all questions honestly (takes ~10-15 minutes)
   - Use the progress tracker to monitor your completion
   - Review your detailed profile analysis upon completion

2. **Exploring Results**
   - View your profile type and detailed parameter scores
   - Explore interactive visualizations of your psychological profile
   - Access personalized strategies and recommendations
   - Compare with previous assessments (if available)

3. **Managing Profiles**
   - Save multiple profiles for comparison
   - Export results as PDF for professional consultation
   - Delete or update existing profiles as needed
