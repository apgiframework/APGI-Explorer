# APGI Explorer

A comprehensive psychological assessment application that helps users understand their cognitive and emotional processing styles through the APGI model. Built with SwiftUI for a seamless cross-platform experience on macOS.

## 🌟 Key Features

### 🧠 Core Psychological Assessment
- **35 scientifically-validated questions** across 7 key dimensions
- **Adaptive scoring algorithm** with reliability weighting for each question
- **Real-time progress tracking** with visual feedback
- **Response validation** to ensure result accuracy and consistency
- **Confidence scoring** that evaluates response patterns for reliability

### 🔍 Advanced Profile Analysis
- **Four Core Parameters**:
  - **Prediction Error Sensitivity (ε)**: Measures sensitivity to unexpected events and changes
  - **Precision Allocation (π)**: Analyzes how you prioritize different information sources
  - **Ignition Threshold (θₜ)**: Assesses your attentional focus and awareness levels
  - **Somatic Bias (β)**: Evaluates your body awareness and interoceptive sensitivity

### 📊 Interactive Visualization & Reporting
- **Dynamic Radar Charts**: Visual representation of your psychological profile with customizable styles
- **State Explorer**: Interactive visualization of 43+ psychological states and transitions
- **Profile Comparison**: Side-by-side comparison with multiple chart types (Radar, Bar, Line)
- **Comprehensive Reports**: Generate detailed PDF, CSV, JSON, and PNG reports for personal or clinical use
- **Advanced Chart Options**: Grid lines, animations, confidence indicators, compact mode

### 🎯 Cognitive Profile Types
Detailed analysis of 8 distinct cognitive profiles, each with unique characteristics, strengths, challenges, and strategies:

1. **Sensitive Integrator** (Orange) - High awareness of prediction errors and bodily responses
2. **Analytical Guard** (Blue) - Strong mental models with precise vigilance
3. **Adaptive Balancer** (Green) - Maintains equilibrium between exploration and stability
4. **Open Explorer** (Pink) - Thrives on novelty and new experiences
5. **Contemplative Anchor** (Teal) - Maintains calm and reflection across contexts
6. **Somatic Navigator** (Purple) - Deeply attuned to bodily sensations and intuition
7. **Cognitive Architect** (Mint) - Strong theoretical and strategic planning abilities
8. **Dynamic Responder** (Red) - Quick to respond to emotional and situational changes

### ⚙️ Comprehensive Settings & Customization
- **9 Settings Categories**: Complete control over app behavior and appearance
  - **General**: Onboarding, behavior, quizzes, profiles, notifications
  - **Appearance**: Themes, accessibility, colors, layout options
  - **Charts & Visualization**: Chart styles, comparison modes, advanced options
  - **Data & Privacy**: Retention policies, analytics, privacy controls
  - **Export & Backup**: Format preferences, quality settings, backup automation
  - **Notifications**: Sound, badges, reminder preferences
  - **Window Management**: Arrangement preferences, layout options
  - **Psychological States**: Display modes, refresh settings, performance options
  - **Advanced**: Debug options, experimental features, system tools
- **Real-time Settings**: All changes apply immediately without restart
- **Reset Options**: Individual setting reset or complete factory reset
- **Import/Export Settings**: Backup and restore your preferences

## 🚀 Getting Started

### Prerequisites
- macOS 12.0+ or iOS 15.0+
- Xcode 14.0+ (for development)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/APGI-Explorer.git
   cd APGI-Explorer
   ```
2. Open `APGI-Explorer.xcodeproj` in Xcode
3. Build and run the project (⌘R)
