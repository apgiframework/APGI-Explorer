# APGI-Signature

A psychological assessment app that helps users understand their cognitive and emotional processing styles based on the Active Predictive Guidance Integration (APGI) model. The app provides a comprehensive analysis of your psychological profile through an interactive quiz and detailed visualizations.

## 🌟 Key Features

### 📝 Interactive Assessment
- 35 carefully crafted questions across multiple psychological dimensions
- Real-time progress tracking and visual feedback
- Adaptive scoring system with reliability weighting
- Response validation to ensure result accuracy

### 🔍 Comprehensive Profile Analysis
- Detailed breakdown of four core psychological parameters:
  - **Prediction Error Sensitivity (ε)**: Your sensitivity to unexpected events and changes
  - **Precision Allocation (π)**: How you prioritize and weight different information sources
  - **Ignition Threshold (θₜ)**: What captures your attention and awareness
  - **Somatic Bias (β)**: Your balance between body awareness and external focus

### 📊 Scoring System
- Weighted question scoring based on reliability metrics
- Cross-parameter interaction analysis
- Temporal stability assessment
- Environmental fit evaluation
- Response pattern validation

### 🎯 Profile Types
Get matched with one of 8 distinct cognitive profiles, each with detailed insights:

1. **Sensitive Integrator** - High awareness of prediction errors and bodily responses
2. **Analytical Guard** - Strong mental models with precise vigilance
3. **Adaptive Balancer** - Maintains equilibrium between exploration and stability
4. **Open Explorer** - Thrives on novelty and new experiences
5. **Contemplative Anchor** - Maintains calm and reflection across contexts
6. **Somatic Navigator** - Deeply attuned to bodily sensations and intuition
7. **Cognitive Architect** - Strong theoretical and strategic planning abilities
8. **Dynamic Responder** - Quick to respond to emotional and situational changes

### 📱 Rich User Experience
- Interactive radar charts for visual profile representation
- Tabbed interface for exploring different aspects of your results
- Personalized feedback and interpretation for each parameter
- Clean, intuitive interface with responsive design

### 💾 Data Management
- Save multiple profiles for comparison
- Export results as PDF for professional consultation
- Secure local storage of assessment data
- Privacy-focused design (all data stays on your device)

### Key Components
- **Quiz Engine**: Handles question flow, validation, and scoring
- **Profile Manager**: Manages saved profiles and results
- **State Explorer**: Interactive visualization of psychological states
- **Export System**: Generates shareable PDF reports

## 🚀 Getting Started

1. **Installation**
   - Clone the repository
   - Open `APGI-Signature.xcodeproj` in Xcode
   - Build and run on your device or simulator

2. **Taking the Assessment**
   - Launch the app and select "Start Quiz"
   - Answer all questions honestly (takes ~10-15 minutes)
   - Review your detailed profile analysis
   - Explore your psychological states and strategies
   - Save or export your results

3. **Exploring Results**
   - View your profile type and detailed parameter scores
   - Explore how your profile interacts with different psychological states
   - Discover personalized strategies based on your cognitive style
   - Compare with previous assessments (if available)
